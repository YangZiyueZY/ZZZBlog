# 代码高亮测试

## TypeScript

```ts
interface User {
  name: string;
  age: number;
}

const user: User = { name: 'KingDove', age: 21 };
console.log(user);
```

## Python

```python
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

print(fibonacci(10))
```
