# 个人主页图片目录

个人主页的徽章与 CG 都由构建期扫描本目录生成，**不需要改代码**。

```
public/img/profile/
├── badges/   # 圆形徽章，1:1 正方形
└── cg/       # 矩形 CG，建议 4:3
```

## 规则

- 支持格式：`.png`、`.jpg`、`.jpeg`、`.webp`、`.avif`、`.gif`、`.svg`
- 每个子目录最多读取 **6 张**；超过 6 张时按文件名升序取前 6 张
- 不足 6 张时按实际数量展示，其余位置隐藏（不保留空占位）
- 徽章建议 ≥ 256×256，CG 建议 ≥ 1280×960，优先 `.webp`
- 命名建议：`01-名称.webp`、`02-名称.webp`……（数字前缀保证顺序稳定；中文名可用）
- 当前 `badges/` 与 `cg/` 中是示例图，可直接删除并替换成自己的图片

## 新增/替换后

- 开发：重新运行 `pnpm dev`（或在运行中的 dev 下刷新；构建期清单在启动时生成）
- 构建：`pnpm build`，然后刷新页面
- 预览/PWA：重新 `pnpm build`，部署后强刷；Service Worker 更新后旧图标/图片可能仍缓存，建议无痕窗口确认
