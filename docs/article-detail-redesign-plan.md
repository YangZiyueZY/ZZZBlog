# 文章详情页 UI 重构计划

> 状态：**计划稿，未改代码**  
> 目标：整体重做文章详情页视觉与信息结构，而不是继续在现有灰色面板上打补丁。  
> 前提：与已改版的个人主页保持同一套视觉语言。

---

## 1. 当前问题（基于现有实现与截图）

### 1.1 信息层级缺失

- 当前页面没有真正的「标题区」：标题来自 Markdown 正文里的 `h1`，前面只有一条 0.78rem 的浅色信息条。
- 没有副标题、摘要、分类、标签、作者、阅读进度等上下文，读者进入页面后直接撞上大标题。
- 元信息（日期、字数、阅读时长、浏览数）全部挤在一条细线上，字号小、对比度低，没有主次。

### 1.2 阅读宽度失控

- 上一轮把正文面板加宽到 1152px（1440 视口），实际正文行宽约 1064px。
- 中文 1.25rem 下每行约 70+ 字，远超舒适阅读区间（约 35–50 个中文字符），眼睛回扫成本高。
- 正文没有最大行宽约束，字号、行高、段距也没有形成节奏。

### 1.3 视觉语言与个人主页割裂

- 当前文章页是一整块 `#1e1e1e` 灰面板 + 4px 纯黑边框，像普通后台内容区。
- 个人主页已经有橙色渐变横幅、黄绿强调色、圆角卡片、`//` 分区标题、粗斜体标题和噪点背景；文章页没有继承这套语言。
- 目录是一张孤立的深色小卡片，与正文、作者、站点导航没有视觉关联。

### 1.4 正文排版问题

- 标题字号断层明显：h1 3rem、h2 2.5rem、h3 2rem，层级过陡，正文颜色几乎纯白。
- 代码块纯黑背景，语言标签和复制按钮默认隐藏，触屏体验差；长代码行缺少明确的横向滚动提示。
- 表格在手机上被压缩，缺少横向滚动容器和视觉边界。
- 图片是 4px 黑边 + 不对称圆角，缺少 figure/caption 语义和统一间距。
- 引用块仍依赖旧式引号图标，和新的卡片/描边体系不一致。

### 1.5 移动端问题

- 信息条会折成两行，日期、统计、标签混在一起。
- 返回按钮悬浮在内容左上，容易压住标题/信息区。
- 目录 FAB 固定在右下，会压住代码块或正文；目录弹层只是简单浮层。
- 正文全宽铺开但没有阅读节奏，长段落、表格、代码在窄屏上显得拥挤。

### 1.6 功能与状态缺口

- 没有阅读进度、没有文末结束标记、没有分享/复制链接、没有上一篇/下一篇。
- 无目录文章（例如只有图片的文章）会和有目录文章产生明显布局跳变。
- 桌面端页面滚动被锁定，正文内部滚动，但缺少「当前读到哪里」的反馈。

---

## 2. 设计方向

### 2.1 概念

把文章详情页做成一个 **绳网档案阅读终端（Archive Reader）**：

- 顶部是文章身份卡（hero）：标题、摘要、标签、作者、时间、封面；
- 中部是克制的阅读正文；
- 右侧是固定阅读轨道：目录 + 进度 + 作者 + 操作；
- 文末给出结束标记和继续阅读入口。

### 2.2 三个原则

1. **先读标题，再读正文**：标题区承担识别与情绪，正文只负责阅读。
2. **宽度服从阅读**：正文列收窄到约 800px（约 45–50 个中文字符），整体页面仍然利用大屏宽度做 hero 与侧栏。
3. **视觉同源**：复用个人主页的橙黄渐变、黄绿强调、圆角卡片、`//` 分区标题和粗斜体标题，而不是另起一套风格。

## 3. 新布局与信息层级

### 3.1 桌面端（≥1200px）

```text
┌─────────────────────────────────────────────────────────────┐
│ Header（固定）                                               │
│ ▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░  阅读进度 2px 渐变条                    │
│                                                             │
│  ← 返回   文章 / 分类                                       │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ HERO                                                   │  │
│  │  标签 / 大标题 / 摘要 / 标签 chips        [封面卡片]    │  │
│  │  作者头像 + 名字 + 等级 · 发布时间 · 更新 · 阅读时长    │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                             │
│  ┌──────────────────────────────┐  ┌─────────────────────┐  │
│  │ 正文（max-width 800px）       │  │ 右侧阅读轨道         │  │
│  │                              │  │ 目录（滚动高亮）     │  │
│  │ 导语 / h2 / h3 / 段落         │  │ 阅读进度环           │  │
│  │ 代码 / 图片 / 表格 / 引用     │  │ 作者小卡             │  │
│  │                              │  │ 复制链接 / 回到顶部  │  │
│  │ 文末结束标记                  │  │                     │  │
│  └──────────────────────────────┘  └─────────────────────┘  │
│                                                             │
│ 上一篇 / 下一篇（可选）                                      │
└─────────────────────────────────────────────────────────────┘
```

- 页面最大宽度约 1280px，hero 横跨正文 + 侧栏。
- 正文列约 800px；右侧栏约 17rem（272px）；间距 2.5rem。
- 目录 sticky 在右侧，滚动高亮；进度环与顶部进度条同步。
- 作者卡固定在目录下方，包含头像、名字、等级、个人主页入口。

### 3.2 移动端（<768px）

```text
┌──────────────────────────────┐
│ ← 返回        目录           │
│ 分类                         │
│ 大标题（2 行内）             │
│ 摘要                         │
│ 标签 chips                   │
│ 作者 · 日期 · 阅读时长       │
│ [封面 16:9，可选]            │
│                              │
│ 正文（左右 1.1rem）          │
│ 代码 / 图片 / 表格           │
│                              │
│ 作者卡                       │
│ 上一篇 / 下一篇（可选）      │
│ [目录 FAB → 底部目录抽屉]    │
└──────────────────────────────┘
```

- 不再把返回键悬浮在正文上，改为 hero 顶部的一枚胶囊按钮。
- 目录 FAB 仍保留，但改成带进度百分比的 pill，点击从底部弹出目录抽屉。
- 封面可选：有 cover 时展示 16:9 横幅；没有则隐藏，不留空位。

### 3.3 信息层级（从高到低）

| 层级 | 内容 | 视觉处理 |
| --- | --- | --- |
| 1 | 标题 | 最大字号、粗斜体、白色、轻微字距 |
| 2 | 摘要 | 次级字号、灰色、限 2–3 行 |
| 3 | 分类 / 标签 | 黄绿胶囊、小字号 |
| 4 | 作者 / 时间 / 阅读时长 | 头像 + 胶囊信息，低对比但不低于 4.5:1 |
| 5 | 正文 | 17px/1.9，暖白，800px 行宽 |
| 6 | 目录 / 进度 | 侧栏低饱和，激活项黄色 |
| 7 | 文末操作 | 低调按钮，不抢正文 |

## 4. 正文排版规范

### 4.1 字号与行距

| 元素 | 桌面 | 移动 | 说明 |
| --- | --- | --- | --- |
| 正文 | 17px / 1.9 | 16px / 1.85 | 中文正文不用 20px，避免松散 |
| 导语（首段） | 18–19px / 1.9 | 17px / 1.85 | 首段略大，颜色更亮 |
| H2 | 30px / 1.3 | 24px / 1.35 | 上方 2.6em、下方 0.9em |
| H3 | 22px / 1.4 | 19px / 1.4 | 上方 2em |
| H4 | 18px / 1.5 | 17px | 不加装饰 |
| 代码 | 14px / 1.75 | 13px / 1.7 | 等宽字体 |
| 表格 | 14px / 1.6 | 13px / 1.55 | 可横向滚动 |
| 图注 | 12–13px | 12px | 灰色、居中 |

- 正文最大行宽：`46em`（约 800px），不随面板无限拉宽。
- 段落间距：`1.35em`；标题前后距用 `em` 随字号缩放。
- 中文标点与中英混排保持系统默认，不引入额外字距。

### 4.2 标题

- H2 前加一条 3px 黄绿渐变竖条 + `//` 前缀（与个人主页分区标题一致）。
- H2/H3 支持 hover 显示锚点 `#`，点击复制当前小节链接。
- 标题不使用纯黑描边；用轻微 text-shadow 保证在背景大字上可读。

### 4.3 段落与强调

- 段落文字色 `#d8d5cf`，强调 `strong` 用 `#fff` + 轻微加粗。
- 行内链接：黄色下划线（offset 3px），hover 变绿。
- 行内代码：暖橙文字 + 低透明橙色底，避免和代码块混淆。

### 4.4 代码块

- 背景 `#080808`，1px `#2a2a2a` 边框，圆角 0.75rem。
- 顶部固定工具条：左侧语言标签，右侧复制按钮；**默认可见**，移动端常显。
- 代码 14px/1.75，横向滚动；滚动条细化；长行不折行。
- 复制成功按钮短暂变绿。

### 4.5 引用

- 左侧 3px 黄绿渐变竖线，背景 `#141414`，圆角 0.6rem。
- 去掉旧引号图标，改为小号 `QUOTE` 标签或保留极简图标。
- 引用内段落行高 1.7，颜色 `#bdb9b2`。

### 4.6 图片

- 统一 `figure`：图片 + 可选图注（取 alt）。
- 圆角 `0 20px 0 20px`（保留个人主页的不对称语言，但减薄）。
- 边框 1px `#2a2a2a`，阴影；`max-height: 80vh`，点击放大。
- 移动端左右 0.5rem，避免顶满屏幕。

### 4.7 表格

- 外层 `overflow-x: auto` 容器，圆角 0.6rem，1px 边框。
- 表头背景 `#1a1a1a`、字号 12px、字母间距 0.04em；单元格 padding 0.7rem 1rem。
- 斑马纹用极低透明度；移动端保留横向滚动，并加左右渐隐提示。

### 4.8 列表、分割线

- 无序列表用黄绿色小方块/圆点，有序列表用等宽数字。
- `hr` 改为渐变细线，居中 60% 宽度。

## 5. 配色与字体

### 5.1 颜色 token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#050505` | 页面底色 |
| `--surface` | `#121212` | 正文面板 |
| `--surface-raised` | `#1a1a1a` | hero / 侧栏 / 卡片 |
| `--border` | `#2c2c2c` | 常规描边 |
| `--text` | `#ece9e2` | 主文字 |
| `--text-secondary` | `#a8a49d` | 摘要、信息 |
| `--text-muted` | `#6f6d68` | 辅助信息 |
| `--accent` | `#F1D801` | 主强调、激活 |
| `--accent-2` | `#6bbd00` | 次强调、成功 |
| `--ember` | `#FF7A1A` | hero 渐变、暖色点缀 |
| `--code-bg` | `#080808` | 代码块 |

- 取消 4px 纯黑边框，改为 1px 边框 + 阴影 + 圆角。
- 重点信息用黄色，状态/成功用绿色，橙色只用于 hero 渐变与少量点缀。
- 正文对比度 ≥ 7:1；辅助文字 ≥ 4.5:1。

### 5.2 字体

- UI / 标题：`Inter, PingFang SC, Microsoft YaHei, Noto Sans SC, system-ui, sans-serif`。
- 正文：同一无衬线字体，保证中英文一致；不加载外部字体，保持离线可用。
- 代码：`JetBrains Mono, ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`。
- 标题使用 900 粗 + 斜体（与个人主页一致）；正文 400，强调 600。

## 6. 与个人主页的统一

- 复用个人主页的 `//` 分区标题和英文小标签（`PROJECTS` / `GALLERY` / `READING`）。
- 复用橙色渐变 hero 语言：文章 hero 用低饱和橙黄渐变 + 噪点，不再整块灰色。
- 圆角统一：面板 1.25rem、卡片 1rem、按钮胶囊 999px。
- 复用头像 + 等级胶囊、黄绿渐变进度、粗斜体标题、深色背景大字水印。
- 右侧目录与作者卡沿用个人主页卡片的边框、hover 与文字层级。
- 迁移时优先复用现有 CSS 变量和 `components.less` 的 token，不新增第二套色板。

## 7. 移动端适配要点

1. 断点：≥1200 双栏；768–1199 单栏（无侧栏，目录抽屉）；<768 紧凑单栏。
2. 返回按钮进入 hero 顶部，不再 fixed 悬浮在正文上。
3. 目录：底部抽屉 + 顶部进度条；抽屉内当前小节高亮，点击后自动收起。
4. 代码块：左右贴边、横向滚动、复制按钮常显。
5. 表格：横向滚动 + 渐隐提示，不压缩字号。
6. 图片：全宽减 0.5rem，点击进入全屏预览；图注 12px。
7. 字号：正文 16px/1.85；H1 2rem；H2 1.5rem；行宽自然撑满。
8. 底部 safe-area：FAB 与抽屉避开 iPhone 底部横条。
9. 减少动效：目录/进度使用 transform/opacity，尊重 `prefers-reduced-motion`。

## 8. 交互与动效

- 顶部 2px 阅读进度条（黄→绿渐变）。
- 目录滚动高亮；点击平滑滚动，移动端点击后收起抽屉。
- 代码复制按钮：默认可见，复制后 1.5s 反馈。
- 图片点击放大，Esc/遮罩关闭，支持移动端下滑关闭（可选）。
- 文末「已读完」标记 + 复制链接 + 回到顶部 + 上一篇/下一篇。
- 所有动效 150–250ms，支持 reduced motion。

## 10. 验收标准

- 1440 / 1200 / 1024 / 390 四档截图与基线对比，视觉无错位。
- 选取 5 篇代表文章：含代码、公式、表格、图片、无目录。
- 正文行宽 760–820px，桌面阅读不出现超长行。
- 目录点击/滚动高亮/移动抽屉/返回按钮全部正常。
- 代码复制、图片放大、页脚/文末操作、PWA 离线不回归。
- 控制台 0 error，`pnpm check`、`pnpm lint`、`pnpm build` 通过。

## 11. 需要你确认的选择

1. **封面**：桌面 hero 右侧放 4:3 封面卡片，移动端 16:9 横幅；没有 cover 时隐藏。是否接受？
2. **正文宽度**：建议收到约 800px（比现在 1064px 窄，但更好读）；还是希望保持更宽？
3. **文末上一篇/下一篇**：是否加入？需要从文章 id 顺序生成。
4. **主题**：保持纯深色（与个人主页一致），还是同时做浅色阅读模式？
5. **作者卡**：桌面右侧固定、移动端正文后展示；是否接受？

> 确认以上方向后，我再开始改代码。
